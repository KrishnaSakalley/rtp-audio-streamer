RTP Audio Streaming Pipeline

A C++17 low-latency audio streamer built from scratch: RFC 3550 RTP packetisation, G.711 mu-law & IMA ADPCM codecs, an adaptive jitter buffer with packet loss concealment, and a lock-free SPSC ring buffer feeding a threaded real-time playout clock. No external RTP, DSP, or codec libraries. Source on GitHub.

Synthetic 440 Hz tone, 4 seconds, 8 kHz mono 16-bit PCM — the source for every comparison below.

5% packet loss, concealment off --no-plc

Same network conditions as below (5% loss, 2% reorder, 30 ms jitter), but with packet loss concealment disabled — lost frames are silence.

5% packet loss, concealment on

Identical network conditions, with the jitter buffer's PLC enabled — lost frames are a faded repeat of the last real frame instead of silence.

IMA ADPCM round trip

Full 4:1 encode/decode round trip through the hand-written ADPCM codec, no network loss.

Try it

git clone https://github.com/KrishnaSakalley/rtp-audio-streamer.git
cd rtp-audio-streamer
cmake -B build -DCMAKE_BUILD_TYPE=RelWithDebInfo
cmake --build build -j
ctest --test-dir build --output-on-failure
See docs/WALKTHROUGH.md for a component-by-component design writeup: the algorithm behind each piece, why it was built that way, and the failure mode if it's wrong.
